Lab 4 – Text Generation Models

This assignment focuses on implementing and comparing multiple text generation techniques using both traditional and deep learning approaches. A custom text corpus related to Artificial Intelligence and Natural Language Processing is used to train models that learn sequential patterns and generate meaningful text. The experiment highlights the strengths and limitations of N-gram models, RNN-based architectures, and Transformer-based models in text generation tasks.

🔹 Models Implemented

N-gram Language Model

Simple Recurrent Neural Network (RNN)

Long Short-Term Memory (LSTM)

Gated Recurrent Unit (GRU)

Transformer Encoder based Text Generation Model

🔹 Key Highlights

Character-level tokenization and sequence modeling

Comparison of sequential vs attention-based architectures

Improved coherence observed in LSTM, GRU, and Transformer models

Implemented using Python, TensorFlow/Keras, and NumP
